# 🎯 Улучшения системы поиска материалов

## ✅ Реализованные улучшения

### 1. 📋 Отображение номеров заказов в статистике

**Проблема:** В таблице статистики по материалам не было видно, в каких именно заказах используется материал.

**Решение:** Добавлена колонка "Номера заказов" с полным списком заказов, где используется материал.

#### Backend изменения:

```sql
-- Добавлен LIST для получения номеров заказов
LIST(DISTINCT o.ORDERNO, ', ') as order_numbers,
```

#### Frontend изменения:

```jsx
<TableHead>
  <TableRow>
    <TableCell>Тип материала</TableCell>
    <TableCell>Материал</TableCell>
    <TableCell>Артикул</TableCell>
    <TableCell>Номера заказов</TableCell> {/* Новая колонка */}
    <TableCell>Заказов</TableCell>
    <TableCell>Изделий</TableCell>
    <TableCell>Количество</TableCell>
    <TableCell>Стоимость</TableCell>
  </TableRow>
</TableHead>
```

#### UX улучшения:

- **Tooltip** для полного отображения номеров заказов
- **Обрезка текста** с многоточием для длинных списков
- **Курсор помощи** при наведении

### 2. 🔄 Улучшенная навигация между секциями

**Проблема:** Пользователь мог не заметить, что есть детальная информация по заказам.

**Решение:** Добавлена кнопка "Показать заказы с материалами" в секции статистики.

```jsx
{
  /* Кнопка для переключения к списку заказов */
}
;<Box mt={2}>
  <Button
    variant="outlined"
    startIcon={<AssignmentIcon />}
    onClick={() => {
      // Прокручиваем к списку заказов
      const ordersSection = document.getElementById('orders-section')
      if (ordersSection) {
        ordersSection.scrollIntoView({ behavior: 'smooth' })
      }
    }}
  >
    Показать заказы с материалами
  </Button>
</Box>
```

## 🎯 Логика работы системы

### 1. **Общий обзор**

- Пользователь видит статистику по материалам с номерами заказов
- Может быстро понять, в каких заказах используется материал

### 2. **Детализация по заказам**

- Кнопка "Показать заказы с материалами" ведет к списку заказов

- При разворачивании заказа показывается:
  - Статистика по материалам этого заказа
  - Детальная информация по изделиям
  - Материалы в каждом изделии

## 🔧 Технические детали

### Backend (Firebird SQL):

```sql
SELECT
  ggt.NAME as stuff_type_name,
  g.NAME as material_name,
  g.MARKING as material_marking,
  LIST(DISTINCT o.ORDERNO, ', ') as order_numbers,
  COUNT(DISTINCT o.ORDERID) as orders_count,
  COUNT(DISTINCT oi.ORDERITEMSID) as items_count,
  SUM(CASE WHEN ... END) as total_quantity,
  SUM(itd.SAVINGCOST) as total_cost
FROM ORDERITEMS oi
JOIN ORDERS o ON o.ORDERID = oi.ORDERID
-- ... остальные JOIN'ы
GROUP BY ggt.ID, ggt.NAME, g.ID, g.NAME, g.MARKING, m.SHORTNAME
```

### Frontend (React):

```jsx
// Отображение номеров заказов с tooltip
;<Tooltip title={material.ORDER_NUMBERS || '-'} placement="top">
  <Typography
    variant="body2"

      textOverflow: 'ellipsis',
      whiteSpace: 'nowrap',
      cursor: 'help',
    }}
  >
    {material.ORDER_NUMBERS || '-'}
  </Typography>
</Tooltip>

// Плавная прокрутка к секции заказов
const ordersSection = document.getElementById('orders-section')

  ordersSection.scrollIntoView({ behavior: 'smooth' })
}
```
