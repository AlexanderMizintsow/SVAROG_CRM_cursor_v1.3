# Логика статистики по материалам

## 🎯 Целевая логика

**Целевой объект**: Материалы (а не заказы)

- Статистика группируется по материалам
- Для каждого материала показывается: в скольких заказах, в скольких изделиях, общее количество и стоимость

## 📊 Уровни группировки

### 1. По типу материала (`stuffType` фильтр)

```sql
GROUP BY ggt.ID, ggt.NAME
```

**Результат**: Статистика по типам материалов (Стеклопакеты, Профиль, и т.д.)

### 2. По конкретному материалу (`materialName` или `materialMarking` фильтр)

```sql
GROUP BY g.ID, g.NAME, g.MARKING, ggt.ID, ggt.NAME, m.SHORTNAME
```

**Результат**: Статистика по конкретным материалам с артикулами

### 3. Общая статистика (без фильтров по материалам)

```sql
GROUP BY ggt.ID, ggt.NAME, g.ID, g.NAME, g.MARKING
```

**Результат**: Статистика по всем материалам

## 🔍 Логика определения группировки

```javascript
// Если есть фильтр по конкретному материалу, группируем по материалу
if (validatedFilters.materialName || validatedFilters.materialMarking) {
  groupByFields = 'g.ID, g.NAME, g.MARKING, ggt.ID, ggt.NAME, m.SHORTNAME'
  grouping = 'by_material'
}
// Если есть фильтр только по типу материала, группируем по типу
else if (validatedFilters.stuffType) {
  groupByFields = 'ggt.ID, ggt.NAME'
  grouping = 'by_type'
}
// Иначе группируем по всем материалам
else {
  groupByFields = 'ggt.ID, ggt.NAME, g.ID, g.NAME, g.MARKING'
  grouping = 'by_all'
}
```

## 🔄 Примеры использования

### 1. Поиск по типу материала

**Фильтр**: `stuffType = 1` (Стеклопакеты)
**Результат**: Статистика по всем стеклопакетам

```
Стеклопакеты: 25 заказов, 80 изделий, 250 м², 30000 ₽
```

### 2. Поиск по артикулу

**Фильтр**: `materialMarking = "SP-4-16-4"`
**Результат**: Статистика по конкретному стеклопакету

```
Стеклопакет 4-16-4: 15 заказов, 45 изделий, 120.5 м², 15000 ₽
```

### 3. Поиск по названию

**Фильтр**: `materialName = "стекло"`
**Результат**: Статистика по всем материалам, содержащим "стекло"

```
Стеклопакет 4-16-4: 15 заказов, 45 изделий, 120.5 м², 15000 ₽
Стеклопакет 6-16-6: 10 заказов, 30 изделий, 80 м², 12000 ₽
```

### 4. Поиск по периоду

**Фильтр**: `startDate = "2024-01-01", endDate = "2024-12-31"`
**Результат**: Статистика по всем материалам за период

```
Профиль: 100 заказов, 300 изделий, 500 м, 50000 ₽
Стеклопакеты: 80 заказов, 200 изделий, 400 м², 40000 ₽
```

## 🎯 Преимущества новой логики

1. **Целевая фокусировка**: Статистика по материалам, а не по заказам
2. **Гибкая группировка**: Автоматический выбор уровня детализации
3. **Полная информация**: Количество, стоимость, единицы измерения
4. **Производительность**: Быстрые запросы с группировкой
5. **Удобство**: Понятная структура данных для анализа
