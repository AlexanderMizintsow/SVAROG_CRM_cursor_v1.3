# Быстрый старт - Десктопные уведомления о звонках

## 🚀 Быстрый запуск для тестирования

### 1. Запуск тестового приложения

```bash
cd Dextop_svarog
electron test-full-system.js
```

### 2. Тестирование функциональности

1. В открывшемся окне нажмите "Отправить уведомление о звонке"
2. Проверьте появление окна уведомления в правом верхнем углу экрана
3. Кликните на уведомление для возврата к основному окну
4. Проверьте логи в консоли разработчика

## 📋 Что было реализовано

### ✅ Основная функциональность:

- **Окно уведомления о звонке** - появляется поверх всех окон
- **Интеграция с веб-приложением** - через Electron API
- **Обработка всех типов звонков** - входящий, активный, завершенный
- **Мигающая иконка в трее** - при входящем звонке
- **Автоматическое закрытие** - через 30 секунд

### ✅ Архитектура:

- **main.js** - основной процесс Electron с логикой уведомлений
- **call-notification.html** - интерфейс окна уведомления
- **preload.js** - API для связи веб-приложения с десктопным
- **useCallNotifications.js** - React хук для интеграции

### ✅ Безопасность:

- Context Isolation включено
- Node Integration отключено
- Безопасный preload script
