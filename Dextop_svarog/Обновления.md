# Обновления проекта

## Анализ уведомлений Windows (текущая сессия)

Я проанализировал проект на предмет наличия уведомлений, которые открываются в Windows.

**Результат анализа:**

- В проекте **ЕСТЬ** система уведомлений для Windows
- Используется Electron API для создания нативных уведомлений Windows
- Реализована через `Notification` класс из Electron
- Уведомления отправляются через IPC (Inter-Process Communication)
- Дополнительно реализовано мигание иконки в системном трее при получении уведомлений

**Технические детали:**

- Уведомления создаются в main.js через `ipcMain.on('send-notification')`
- Клиентская часть может отправлять уведомления через `electronAPI.sendNotification()`
- При получении уведомления иконка в трее начинает мигать, если окно не в фокусе
- Мигание останавливается при показе или фокусе окна приложения

## Исправление ошибки "не является приложением Win32" (текущая сессия)

**Проблема:**
После установки на некоторых Windows при запуске происходила ошибка "не является приложением Win32"

**Решение:**

1. Обновлена конфигурация сборки в package.json для поддержки обеих архитектур (x64 и ia32)
2. Понижена версия Electron с ^36.4.0 до ^28.0.0 для лучшей совместимости
3. Обновлен electron-builder до ^24.0.0
4. Добавлены настройки NSIS для корректной установки

**Изменения в package.json:**

- Добавлен блок "win" с поддержкой архитектур x64 и ia32
- Настроен NSIS инсталлятор с возможностью выбора директории установки
- Добавлены ярлыки на рабочий стол и в меню "Пуск"

**Результат исправления:**

- Создан универсальный установщик Dextop Setup 1.0.0.exe (136MB)
- Установщик поддерживает как 32-битные (ia32), так и 64-битные (x64) системы Windows
- Использована стабильная версия Electron 28.3.3 для лучшей совместимости
- Сборка прошла успешно без ошибок

## Исправление ошибки "Точка входа не найдена" (текущая сессия)

**Проблема:**
После исправления первой ошибки появилась новая: "Точка входа в процедуру DiscardVirtualMemory не найдена в библиотеке DLL KERNEL32.dll"

**Причина:**
Electron 28.3.3 использует API функции, которые недоступны на старых версиях Windows

**Решение:**

1. Понижена версия Electron с ^28.0.0 до ^22.3.0 для максимальной совместимости
2. Добавлен параметр "requestedExecutionLevel": "asInvoker" для корректных прав доступа
3. Пересобран проект с новой версией Electron

**Результат исправления:**

- Создан новый установщик с Electron 22.3.27
- Улучшена совместимость со старыми версиями Windows
- Сборка прошла успешно
- Приложение должно работать на Windows 7 и выше
