# Обновление поля ИНН - Снятие ограничений

## Описание изменений

Поле ИНН в приложении было обновлено для снятия ограничений по количеству символов и типу вводимых данных. Теперь можно вводить как цифры, так и буквы без ограничений по длине.

## Изменения в базе данных

### Обновленные таблицы:

1. **companies** - основная таблица компаний
2. **orders_1c** - таблица заказов из 1С
3. **reclamation_records** - таблица рекламационных записей

### Изменения:

- `VARCHAR(12)` → `VARCHAR(255)` для всех полей ИНН
- Удалены комментарии о ограничениях "10 или 12 цифр"

## Изменения в клиентской части

### Обновленные компоненты:

1. **CompanyForm.jsx** - форма создания компании
   - Добавлен `maxLength="255"` для поля ИНН
2. **EditCompanyGeneralInfo.jsx** - форма редактирования компании
   - Добавлен `maxLength="255"` для поля ИНН

## Файлы для обновления существующей БД

### update_inn_field.sql

Скрипт для обновления существующей базы данных:

```sql
-- Обновление таблицы companies
ALTER TABLE companies ALTER COLUMN inn TYPE VARCHAR(255);

-- Обновление таблицы orders_1c
ALTER TABLE orders_1c ALTER COLUMN inn TYPE VARCHAR(255);

-- Обновление таблицы reclamation_records (если существует)
DO $$
BEGIN
    IF EXISTS (SELECT 1 FROM information_schema.tables WHERE table_name = 'reclamation_records') THEN
        ALTER TABLE reclamation_records ALTER COLUMN inn TYPE VARCHAR(255);
    END IF;
END $$;
```

## Что НЕ изменилось

1. **Внешние API** - функция `getCompanyDataEGRUL` в Telegram боте продолжает работать как прежде
2. **Уникальность** - ограничение UNIQUE для поля ИНН в таблице companies сохранено
3. **Логика приложения** - вся бизнес-логика работает без изменений
