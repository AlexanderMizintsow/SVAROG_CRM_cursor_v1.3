# 🔧 Исправление отображения количества материала

## ❌ **Проблема:**

Пользователь спросил:

```
тогда что значит 520 экземпляров материала если он в метрах а не штуках?
```

**Проблема:** Показывалось количество **записей** в базе данных (520 экземпляров), а не физическое количество материала в единицах измерения.

## 🔍 **Анализ проблемы:**

### **Было (неправильно):**

```javascript
// В контроллере
const totalMaterials = stats.TOTAL_MATERIAL_INSTANCES // COUNT(itd.GOODSID)
```

**SQL запрос:**

```sql
COUNT(itd.GOODSID) as TOTAL_MATERIAL_INSTANCES  -- ← Считает записи в БД
```

**Что это означало:**

- **520 экземпляров** = 520 записей в таблице `ITEMSDETAIL`
- Каждая запись может содержать разное количество материала
- Например: запись 1 = 2.5 метра, запись 2 = 1.8 метра, запись 3 = 3.2 метра
- **Итого:** 520 записей, но реальное количество материала = 7.5 метров

## 🔧 **Решение:**

### **Исправлено в `server/AW/controllers/statisticsController_new.js`:**

```javascript
// БЫЛО (неправильно):
const totalMaterials = stats.TOTAL_MATERIAL_INSTANCES // Количество записей

// СТАЛО (правильно):
const totalMaterials = Math.round(stats.TOTAL_QUANTITY * 100) / 100 // Количество материала в единицах измерения
```

### **Обновлен текст на клиенте:**

```javascript
// client/src/routes/statistics/MaterialSearchPage.jsx
// БЫЛО:
<Chip label={`${searchStats.totalMaterials} экземпляров материала`} color="info" />

// СТАЛО:
<Chip label={`${searchStats.totalMaterials} единиц материала`} color="info" />
```

## 🎯 **Логика расчета:**

### **TOTAL_MATERIAL_INSTANCES (старый способ):**

```sql
COUNT(itd.GOODSID) as TOTAL_MATERIAL_INSTANCES
```

- Считает количество **записей** в таблице `ITEMSDETAIL`
- Не учитывает реальное количество материала

### **TOTAL_QUANTITY (новый способ):**

```sql
SUM(
  CASE
    WHEN (itd.ISEXTENDED = 1) THEN itd.QTY*itd.THICK/m.AMFACTOR
    ELSE itd.QTY*itd.THICK*oi.QTY/m.AMFACTOR
  END
) as TOTAL_QUANTITY
```

- Считает **реальное количество** материала с учетом единиц измерения
- Учитывает `AMFACTOR` для правильного пересчета
