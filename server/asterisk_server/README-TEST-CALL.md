# Тест симуляции звонка

Скрипт `simulate-call.js` имитирует входящий звонок на указанный номер, минуя Asterisk. Подходит для проверки модальных окон и логики уведомлений.

## Подготовка

1. **Номер 777 в CRM**  
   В карточке пользователя (Настройки → Пользователи → редактирование) добавьте номер телефона `777` в поле телефона.

2. **CRM-сервер запущен**  
   Порт 5004 (сервер с Socket.IO для звонков).

3. **Пользователь залогинен**  
   В браузере откройте CRM и войдите под пользователем, у которого в `user_phones` есть номер `777`.

## Запуск

```bash
cd server/asterisk_server
npm run test-call
```

Или напрямую:

```bash
node simulate-call.js
```

## Параметры

```bash
# Звонок на 777 от 79001234567 (по умолчанию)
node simulate-call.js

# Звонок на другой внутренний номер (например, 100)
node simulate-call.js 100

# Звонок на 777 от указанного номера
node simulate-call.js 777 79009999999
```

Скрипт автоматически отправляет все три фазы: входящий → активный → завершён.

## Переменные окружения (.env)

| Переменная        | По умолчанию         | Описание                              |
|-------------------|----------------------|---------------------------------------|
| CRM_SOCKET_URL    | http://127.0.0.1:5004| Адрес CRM Socket.IO                   |
| TEST_CALLER_NUMBER| 79001234567          | Номер «звонящего» при симуляции       |
| DB_*              | postgres/localhost...| Подключение к БД для поиска user_phones|

## Что происходит

1. Скрипт находит пользователя с номером 777 в БД.
2. Подключается к CRM по Socket.IO.
3. Отправляет события: `incoming_call` → `call_started` → `call_ended`.
4. В CRM должно появиться модальное окно с «Тестовый звонок» и номером звонящего.

## Заметка

Симуляция не создаёт запись в таблице `calls`. Сохранение данных звонка (цель, описание, итог) при нажатии «Сохранить» может вернуть ошибку — это ожидаемо, так как звонок виртуальный.
