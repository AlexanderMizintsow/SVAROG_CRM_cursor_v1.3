# Движок бизнес-процессов (BPE)

Перед первым запуском:

1. **Установите зависимости:** из корня проекта выполните  
   `npm run install:bpe`  
   либо из этой папки: `npm install`

2. **Настройте окружение:** скопируйте `.env.example` в `.env` и укажите параметры БД и URL сервисов (register, tg-bot).

3. **Создайте таблицы в БД:** выполните SQL из `db/SQL_MANUAL_QUERIES.sql` в вашей PostgreSQL (SVAROG_DB).

4. **Запуск:** `node index.js` или `npm run dev` (с nodemon). По умолчанию сервер слушает порт 5010.

В корневом `package.json` скрипт `npm run dev` запускает BPE вместе с остальными сервисами.
