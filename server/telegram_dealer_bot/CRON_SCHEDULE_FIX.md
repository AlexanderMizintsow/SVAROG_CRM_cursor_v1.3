# Исправление расписания cron задач

## Проблема

В 12:00 запускались одновременно две cron задачи:

- `reclamation` (12:00) - проверка рекламаций
- `orders1c_late_response` (12:00) - проверка поздних ответов

Это приводило к блокировке event loop и пропуску последующих задач.

## Решение

Изменено время выполнения `orders1c_late_response` с **12:00** на **12:10**.

### Изменения в файле `queryLines/orders1c/orders1c.js`:

**Было:**

```javascript
'0 12 * * *' // 12:00
```

**Стало:**

```javascript
'10 12 * * *' // 12:10
```

## Новое расписание cron задач

| Время | Задача                 | Описание                 |
| ----- | ---------------------- | ------------------------ |
| 9:00  | orders1c               | Обработка заказов 1С     |
| 9:35  | reconciliation         | Сверка заказов           |
| 10:00 | reclamation            | Проверка рекламаций      |
| 12:00 | reclamation            | Проверка рекламаций      |
| 12:10 | orders1c_late_response | Проверка поздних ответов |
| 14:00 | reclamation            | Проверка рекламаций      |
| 16:00 | reclamation            | Проверка рекламаций      |
| 18:00 | reclamation            | Проверка рекламаций      |

## Результат

- ✅ Устранен конфликт в 12:00
- ✅ Задачи выполняются с интервалом 10 минут
- ✅ Event loop не блокируется
- ✅ Предотвращены пропуски выполнения

## Применение изменений

После изменения файла необходимо перезапустить сервер:

```bash
# Если через PM2
pm2 restart telegram-dealer-bot-server

# Или остановить и запустить заново
pm2 stop telegram-dealer-bot-server
pm2 start index.js --name telegram-dealer-bot-server
```
