# Статистика заказов - Руководство пользователя

## Описание

Компонент статистики заказов позволяет анализировать материалы и изделия по заказам с возможностью фильтрации по различным параметрам. Это особенно полезно для определения количества использованных материалов за определенный период.

## Функциональность

### Основные возможности:

- **Фильтрация по датам** - выбор периода создания заказов
- **Фильтрация по статусу** - заказы в производстве (4) или закрытые (3)
- **Фильтрация по типу товара** - профиль, стеклопакеты, армирование и т.д.
- **Поиск по материалу** - поиск конкретных материалов по названию
- **Выбор года** - работа с базами данных разных лет
- **Два режима отображения**:
  - Детальная статистика - полная информация по каждому изделию
  - Сводная статистика - агрегированные данные по материалам

### API Endpoints

#### 1. Получение детальной статистики

```
POST /app/statistics/orders
```

**Параметры запроса:**

```json
{
  "startDate": "2024-01-01", // Дата начала (опционально)
  "endDate": "2024-12-31", // Дата окончания (опционально)
  "orderStatus": 4, // Статус заказа (3-закрыт, 4-в производстве)
  "stuffType": "Profil", // Тип товара (опционально)
  "materialName": "сэндвич", // Название материала (опционально)
  "year": "2025" // Год базы данных
}
```

#### 2. Получение сводной статистики

```
POST /app/statistics/summary
```

**Параметры запроса:**

```json
{
  "startDate": "2024-01-01",
  "endDate": "2024-12-31",
  "orderStatus": 4,
  "year": "2025"
}
```

#### 3. Получение типов товаров

```
GET /app/statistics/stuff-types/2025
```

## Структура данных

### Детальная статистика возвращает:

- `ORDERNO` - номер заказа
- `ITEM_NAME` - название изделия
- `MATERIAL_NAME` - название материала
- `ITEM_DESC` - тип товара
- `ITEM_ART` - артикул
- `W`, `H`, `L` - размеры (ширина, высота, толщина)
- `ITEM_QTY` - количество
- `ITEM_PRICE` - стоимость
- `ORDERSTATUS` - статус заказа
- `DATECREATED` - дата создания

### Сводная статистика возвращает:

- `STUFF_TYPE` - тип материала
- `MATERIAL_NAME` - название материала
- `MARKING` - маркировка
- `ORDERS_COUNT` - количество заказов
- `ITEMS_COUNT` - количество изделий
- `TOTAL_QTY` - общее количество
- `TOTAL_COST` - общая стоимость

## Типы товаров (STUFFTYPES)

Основные типы товаров в системе:

- **Profil** - Профиль
- **SP** - Стеклопакеты
- **Армирование** - Армирование
- **Уплотнение** - Уплотнители
- **Штапик** - Штапики
- **Сэндвич** - Сэндвич-панели
- **Работы** - Работы
- **Комплектующие** - Комплектующие
- **Фурнитура на сборку** - Фурнитура
- **Шурупы** - Крепежные элементы

## Статусы заказов

- **3** - Закрыт (завершен)
- **4** - В производстве (активный)

## Экспорт данных

Компонент поддерживает экспорт данных в CSV формат:

- Кнопка "Экспорт CSV" в интерфейсе
- Автоматическое именование файла с датой
- Поддержка как детальной, так и сводной статистики

## Устранение неполадок

### Ошибка подключения к БД

- Проверьте настройки в `.env` файле
- Убедитесь, что сервер AW запущен на порту 5005
- Проверьте доступность базы данных Firebird

### Пустые результаты

- Проверьте правильность фильтров
- Убедитесь, что в выбранном периоде есть данные
- Проверьте статус заказов

### Медленная работа

- Ограничьте период выборки
- Используйте более специфичные фильтры
- Проверьте индексы в базе данных

## Контакты

При возникновении проблем обращайтесь к администратору системы.
