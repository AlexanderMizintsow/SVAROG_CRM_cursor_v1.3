# Быстрый старт - Статистика заказов

## Запуск сервера

1. Перейдите в папку сервера:

```bash
cd server/AW
```

2. Установите зависимости (если не установлены):

```bash
npm install
```

3. Запустите сервер:

```bash
npm start
```

Сервер будет доступен по адресу: `http://localhost:5005`

## Запуск клиента

1. Перейдите в папку клиента:

```bash
cd client
```

2. Установите зависимости (если не установлены):

```bash
npm install
```

3. Запустите клиент:

```bash
npm run dev
```

Клиент будет доступен по адресу: `http://localhost:5173`

## Доступ к статистике

1. Откройте браузер и перейдите на `http://localhost:5173`
2. Войдите в систему
3. В левом меню найдите "Статистика заказов" в разделе "Дилеры"
4. Нажмите на пункт меню

## Первое использование

1. Выберите период (дата начала и окончания)
2. Выберите статус заказа (опционально)
3. Выберите тип товара (опционально)
4. Введите название материала для поиска (опционально)
5. Укажите год базы данных (по умолчанию 2025)
6. Нажмите "Поиск"

## Примеры запросов

### Найти все сэндвич-панели за март 2024:

- Дата начала: 01.03.2024
- Дата окончания: 31.03.2024
- Наименование материала: "сэндвич"

### Найти все заказы в производстве:

- Статус заказа: "В производстве"

### Найти все профили:

- Тип товара: "Профиль"

## Экспорт данных

После получения результатов нажмите кнопку "Экспорт CSV" для сохранения данных в файл.

## Поддержка

При возникновении проблем проверьте:

1. Запущен ли сервер AW на порту 5005
2. Доступна ли база данных Firebird
3. Правильно ли настроены переменные окружения в `.env` файле

## Устранение неполадок

### Ошибка 504 Outdated Optimize Dep

Если при запуске клиента возникает ошибка с `@mui/x-date-pickers`:

1. Очистите кэш Vite:

```bash
cd client
rm -rf node_modules/.vite
npm run dev
```

2. Если проблема сохраняется, перезапустите dev сервер

3. Подробная инструкция в файле `client/TROUBLESHOOTING.md`

### Поля дат

В компоненте используются стандартные HTML поля дат вместо DatePicker для лучшей совместимости.
