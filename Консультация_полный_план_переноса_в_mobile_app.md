# Консультация: полный план переноса в мобильное приложение

Документ фиксирует раздел **`/consultation`** из `server/telegram_dealer_bot` для переноса в `apk/POZ` + `server/mobile_app`.

**Интеграции:** нет 1С и нет AW. Контент — **статические ссылки** на видео (Яндекс.Диск) в коде **`consultation.js`**.

---

## 1) Источники текущей логики

| Назначение | Файл |
|------------|------|
| Меню консультации | `server/telegram_dealer_bot/queryLines/consultation/consultation.js` — `handleConsultation` |
| Список видео | `handleConsultationCalculate` — кнопки с `url: 'https://disk.yandex.ru/...'` |
| Маршруты | `server/telegram_dealer_bot/helpers/chatCommandHandler.js` — `/consultation`, `/consultation_how_calculate` |
| Доп. ветка в `auth.js` | `command === '/consultation_how_calculate' \|\| userSessions[chatId].consultationVideo` |

---

## 2) Поведение в Telegram

1. **`handleConsultation`:** сообщение «Выберите действие», кнопка **«Как считать? (видео)»** → callback **`/consultation_how_calculate`**. Пункт «Ассортимент» в коде закомментирован.
2. **`handleConsultationCalculate`:** выводится набор **inline-кнопок с URL** — каждая открывает ролик на Яндекс.Диске (вводная часть, балконный блок, лоджия, стеклопакет, двери, окно, Проведаль, москитная сетка, створки и т.д.).

---

## 3) Перенос в POZ + `mobile_app`

| Задача | Рекомендация |
|--------|----------------|
| Конфигурация | Вынести **категории + подписи + URL** в **БД или JSON на сервере** (`GET /mobile/consultation/videos`), чтобы обновлять ссылки без релиза APK/IPA. |
| UI | Список/аккордеон по темам; открытие во внешнем браузере или in-app WebView (учесть регионы и лимиты Яндекса). |
| Офлайн | Показать понятное сообщение, если нет сети. |
| Приоритет | **P3** в общей дорожной карте. |

---

## 4) Паритет с ботом (чеклист)

- [ ] Набор тем покрывает те же обучающие сценарии, что и кнопки в боте (или расширенный список с версионированием API).
- [ ] Нет вызовов 1С с устройства.
- [ ] Ссылки не захардкожены только в клиенте (рекомендация: серверный конфиг).
