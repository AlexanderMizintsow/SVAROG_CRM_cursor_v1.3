# 🔧 Исправление логики фильтрации по датам

## ❌ Проблема

При фильтрации заказов по диапазону дат наблюдалось нелогичное поведение:

- Диапазон **2025-09-01 до 2025-09-02** (2 дня) показывал больше заказов
- Диапазон **2025-09-01 до 2025-09-05** (5 дней) показывал меньше заказов

Это противоречит логике: чем больше диапазон дат, тем больше заказов должно быть найдено.

## 🔍 Анализ проблемы

### 1. Проблема с типом данных

В таблице `ORDERS` поле `DATECREATED` имеет тип `TIMESTAMP`, который включает время. При сравнении:

- `o.DATECREATED >= '2025-09-01'` - правильно
- `o.DATECREATED <= '2025-09-02'` - **проблема!**

Если заказ создан 02.09.2025 в 15:30, то:

- `'2025-09-02'` интерпретируется как `'2025-09-02 00:00:00'`
- Заказ с временем `15:30` **НЕ попадает** в условие `<= '2025-09-02 00:00:00'`

### 2. Неправильная логика сравнения

При фильтрации по дате окончания нужно включать весь день, а не только начало дня.

## ✅ Решение

### 1. Использование CAST для приведения к DATE

**Было:**

```sql
o.DATECREATED >= ?
o.DATECREATED <= ?
```

**Стало:**

```sql
CAST(o.DATECREATED AS DATE) >= ?
CAST(o.DATECREATED AS DATE) <= ?
```

### 2. Логика работы

Теперь сравнение происходит по датам без учета времени:

- `CAST(o.DATECREATED AS DATE) >= '2025-09-01'` - заказы от 01 сентября
- `CAST(o.DATECREATED AS DATE) <= '2025-09-02'` - заказы до 02 сентября включительно

### 3. Примеры

**Диапазон 01-02 сентября:**

```sql
WHERE CAST(o.DATECREATED AS DATE) >= '2025-09-01'
  AND CAST(o.DATECREATED AS DATE) <= '2025-09-02'
```

Найдет заказы за 01 и 02 сентября (независимо от времени)

**Диапазон 01-05 сентября:**

```sql
WHERE CAST(o.DATECREATED AS DATE) >= '2025-09-01'
  AND CAST(o.DATECREATED AS DATE) <= '2025-09-05'
```

Найдет заказы за 01, 02, 03, 04, 05 сентября (независимо от времени)

### 1. Файл: `server/AW/utils/statisticsUtils.js`

**Функция `buildWhereConditions`:**

```javascript
// Было
if (filters.startDate) {
  conditions.push('o.DATECREATED >= ?')
  params.push(filters.startDate)
}
if (filters.endDate) {
  conditions.push('o.DATECREATED <= ?')
  params.push(filters.endDate)
}

// Стало
if (filters.startDate) {
  conditions.push('CAST(o.DATECREATED AS DATE) >= ?')
  params.push(filters.startDate)
}
if (filters.endDate) {
  conditions.push('CAST(o.DATECREATED AS DATE) <= ?')
  params.push(filters.endDate)
}
```
