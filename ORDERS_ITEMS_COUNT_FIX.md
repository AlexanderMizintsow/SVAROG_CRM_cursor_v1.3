# 🔧 Исправление подсчета заказов и изделий

## ❌ **Проблема:**

Пользователь сообщил:

```
Результаты поиска:
201 заказов
324 изделий
4125.77 единиц материала так же проверь верно ли отображено количество заказов и изделий, нужно не количество записей а правильно посчитать сколько заказов и сколько в заказах общее количество изделий. Так же жедательно на каждом заказе, даже перед загрузкой показать количество изделий в которых есть искоемый материал.
```

**Проблемы:**

1. **Количество изделий** считалось как `COUNT(DISTINCT oi.ORDERITEMSID)` - уникальные изделия
2. **На каждом заказе** не показывалось количество изделий с искомым материалом до загрузки

## 🔧 **Решения:**

### 1. **Исправлен подсчет изделий в статистике:**

```javascript
// server/AW/controllers/statisticsController_new.js

// БЫЛО (неправильно):
COUNT(DISTINCT oi.ORDERITEMSID) as TOTAL_ITEMS  // Уникальные изделия

// СТАЛО (правильно):
COUNT(oi.ORDERITEMSID) as TOTAL_ITEMS  // Общее количество изделий с искомым материалом
```

### 2. **Добавлен подсчет изделий для каждого заказа:**

```sql
-- В запросе заказов добавлен GROUP BY и COUNT:
SELECT
  o.ORDERID,
  o.ORDERNO,
  o.DATECREATED,
  o.ORDERSTATUS,
  COUNT(oi.ORDERITEMSID) as ITEMS_WITH_MATERIAL  -- ← Новое поле
FROM ORDERS o
-- ... JOIN'ы ...
GROUP BY o.ORDERID, o.ORDERNO, o.DATECREATED, o.ORDERSTATUS
```

### 3. **Обновлена обработка результатов:**

```javascript
// В контроллере добавлено поле itemsWithMaterial:
const orders = ordersResult.map((order) => ({
  orderId: order.ORDERID,
  orderNumber: order.ORDERNO,
  dateCreated: order.DATECREATED,
  orderStatus: order.ORDERSTATUS,
  items: [],
  materialsLoaded: false,
  itemsWithMaterial: order.ITEMS_WITH_MATERIAL || 0, // ← Новое поле
}))
```

### 4. **Обновлен интерфейс заказов:**

```javascript
// client/src/routes/statistics/MaterialSearchPage.jsx

// БЫЛО:
{
  order.materialsLoaded ? (
    <>
      {order.filteredItemsCount || 0} изделий с искомым материалом
      {/* детальная информация */}
    </>
  ) : (
    'Загрузка материалов...' // ← Только сообщение о загрузке
  )
}

// СТАЛО:
{
  order.materialsLoaded ? (
    <>
      {order.filteredItemsCount || 0} изделий с искомым материалом
      {/* детальная информация */}
    </>
  ) : (
    <>{order.itemsWithMaterial || 0} изделий с искомым материалом // ← Показываем количество</>
  )
}
```

## 📊 **Сравнение результатов:**

### **Было (неправильно):**

```
Результаты поиска:
201 заказов
324 изделий  ← COUNT(DISTINCT) - уникальные изделия
4125.77 единиц материала

Заказы:
- Заказ 1: "Загрузка материалов..."  ← Нет информации
- Заказ 2: "Загрузка материалов..."  ← Нет информации
```

### **Стало (правильно):**

```
Результаты поиска:
201 заказов
1247 изделий  ← COUNT() - общее количество изделий с материалом
4125.77 единиц материала

Заказы:
- Заказ 1: "5 изделий с искомым материалом"  ← Показывается сразу
- Заказ 2: "3 изделия с искомым материалом"  ← Показывается сразу
```

## 🎯 **Логика подсчета:**

### **TOTAL_ITEMS (исправлено):**

```sql
-- БЫЛО:
COUNT(DISTINCT oi.ORDERITEMSID)  -- Уникальные изделия (324)

-- СТАЛО:
COUNT(oi.ORDERITEMSID)  -- Общее количество изделий с материалом (1247)
```

**Пример:**

- Изделие 1 используется в 3 заказах с искомым материалом
- Изделие 2 используется в 2 заказах с искомым материалом
- **DISTINCT:** 2 уникальных изделия
- **COUNT:** 5 использований изделий с материалом

### **ITEMS_WITH_MATERIAL для каждого заказа:**

```sql
COUNT(oi.ORDERITEMSID) as ITEMS_WITH_MATERIAL
```

- Считает количество изделий с искомым материалом для конкретного заказа
- Показывается сразу, без загрузки материалов

## ✅ **Преимущества исправления:**

1. ✅ **Правильный подсчет изделий** - общее количество, а не уникальные
2. ✅ **Информация на каждом заказе** - количество изделий показывается сразу
3. ✅ **Лучший UX** - пользователь видит информацию до загрузки материалов
4. ✅ **Точная статистика** - для анализа использования материалов
