# Десктопные уведомления о звонках

## Описание

Система десктопных уведомлений о звонках для приложения SVAROG CRM. При поступлении входящего звонка появляется отдельное окно уведомления поверх всех других окон, которое позволяет пользователю быстро перейти к основному приложению.

## Функциональность

### Основные возможности:

- **Окно уведомления о звонке**: Появляется в правом верхнем углу экрана при входящем звонке
- **Всегда поверх других окон**: Уведомление отображается поверх всех открытых приложений
- **Клик для открытия**: При клике на уведомление открывается/восстанавливается основное приложение
- **Автоматическое закрытие**: Окно уведомления автоматически закрывается через 30 секунд
- **Мигающая иконка в трее**: Иконка в системном трее мигает при входящем звонке

### Типы уведомлений:

- **Входящий звонок** (`incoming_call`)
- **Активный звонок** (`call_started`)
- **Завершенный звонок** (`call_ended`)

## Архитектура

### Компоненты:

1. **main.js** - Основной процесс Electron с логикой уведомлений
2. **call-notification.html** - HTML интерфейс окна уведомления
3. **preload.js** - API для связи между веб-приложением и десктопным
4. **useCallNotifications.js** - Хук React для интеграции с веб-приложением

### Поток данных:

```
WebSocket (CRM Server) → React Hook → Electron API → Desktop Notification Window
```

## Интеграция с веб-приложением

### В React компоненте:

```javascript
import useCallNotifications from "../hooks/useCallNotifications";

const MyComponent = () => {
  const { currentCall, isConnected } = useCallNotifications();

  // currentCall содержит данные о текущем звонке
  // isConnected показывает статус подключения к серверу

  return (
    <div>{currentCall && <CallNotification callData={currentCall} />}</div>
  );
};
```

### API методы:

```javascript
// Проверка доступности Electron API
if (window.electronAPI) {
  // Отправка обычного уведомления
  window.electronAPI.sendNotification(title, body);

  // Отправка уведомления о звонке
  window.electronAPI.sendCallNotification(callData);

  // Отправка уведомления о завершении звонка
  window.electronAPI.sendCallEnded(callData);
}
```

## Настройки окна уведомления

### Позиция и размер:

- **Размер**: 350x200 пикселей
- **Позиция**: Правый верхний угол экрана (20px отступ)
- **Всегда поверх**: `alwaysOnTop: true`
- **Без рамки**: `frame: false`

### Поведение:

- **Автозакрытие**: 30 секунд
- **Клик для открытия**: Основное приложение
- **Кнопка закрытия**: В правом верхнем углу уведомления

## Устранение неполадок

### Проблема: Уведомления не появляются

**Решение:**

1. Проверьте, что CRM сервер запущен на порту 5004
2. Убедитесь, что пользователь авторизован в системе
3. Проверьте консоль браузера на наличие ошибок WebSocket

### Проблема: Electron API недоступен

**Решение:**

1. Убедитесь, что приложение запущено через Electron
2. Проверьте, что preload.js правильно настроен
3. Проверьте консоль Electron на наличие ошибок

### Проблема: Окно уведомления не появляется

**Решение:**

1. Проверьте, что call-notification.html существует
2. Убедитесь, что main.js правильно обрабатывает события
3. Проверьте консоль Electron на наличие ошибок
