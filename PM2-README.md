# 🚀 SVAROG - Управление серверами через PM2

## 📋 Список серверов

Всего **9 серверов** в системе:

1. **asterisk-server** - Asterisk сервер
2. **aw-server** - AW сервер
3. **CRM-server** - CRM сервер
4. **dealer-server** - Дилерский сервер
5. **register-service** - Сервис регистрации
6. **telegram_dealer_bot-server** - Telegram бот для дилеров
7. **tg-bot-server** - Telegram бот сервер
8. **email-service** - Email сервис
9. **SVAROG** - Клиентское приложение (порт 5173)

## 🎯 Быстрый запуск

### Вариант 1: Двойной клик (рекомендуется)

Просто дважды кликните на файл `start-servers.bat`

### Вариант 2: Ручной запуск

Выполните команды из файла `client/src/main.jsx`

Дважды кликните на файл `stop-servers.bat`

### Вариант 2: Через командную строку

```bash
pm2 stop all

pm2 save
```

## ⏰ Автоматическая перезагрузка

Все серверы автоматически перезагружаются **каждый день в 7:50 утра** через Windows Task Scheduler.

### Настройка расписания

Дважды кликните на файл `setup-windows-scheduler.bat`

### Удаление расписания

Дважды кликните на файл `remove-auto-restart.bat`

### Ручная настройка через командную строку

```bash
# Создание задачи
schtasks /create /tn "SVAROG-Restart" /tr "pm2 restart all" /sc daily /st 07:50

# Изменение времени
schtasks /change /tn "SVAROG-Restart" /st 08:00

# Удаление задачи
schtasks /delete /tn "SVAROG-Restart"
```

### Изменение времени перезагрузки

Измените время в файлах:

- `"50 7 * * *"` = 7:50 каждый день
- `"0 8 * * *"` = 8:00 каждый день
- `"30 6 * * *"` = 6:30 каждый день

## 📊 Управление PM2

### Просмотр процессов

```bash
pm2 list
```

### Просмотр логов

```bash
pm2 logs [имя_сервера]
pm2 logs all
```

### Перезапуск конкретного сервера

```bash
pm2 restart [имя_сервера]
```

### Перезапуск всех серверов

```bash
pm2 restart all
```

### Сохранение конфигурации

```bash
pm2 save
```

### Автозапуск при загрузке системы

```bash
pm2 startup install
pm2 save
```

## 🔧 Устранение неполадок

### Если сервер не запускается

1. Проверьте, что файл `index.js` существует в папке сервера
2. Проверьте логи: `pm2 logs [имя_сервера]`
3. Убедитесь, что порты не заняты другими процессами
4. Попробуйте перезапустить: `pm2 restart all`

### Если PM2 не работает

```bash
npm install -g pm2
npm install pm2-windows-startup -g
pm2-startup install
```

### Полная очистка PM2

```bash
pm2 kill
pm2 delete all
pm2 save
```

## ✅ Проверка работоспособности

После запуска проверьте:

1. `pm2 list` - все серверы должны быть в статусе "online"
2. Клиент доступен по адресу: `http://localhost:5173`
3. Логи не содержат критических ошибок: `pm2 logs all`

## 🕐 Cron выражения

Для изменения времени перезагрузки используйте cron выражения:

| Выражение        | Описание                |
| ---------------- | ----------------------- |
| `"50 7 * * *"`   | 7:50 каждый день        |
| `"0 8 * * *"`    | 8:00 каждый день        |
| `"30 6 * * *"`   | 6:30 каждый день        |
| `"0 6 * * 1"`    | 6:00 каждый понедельник |
| `"0 12 * * 1-5"` | 12:00 в рабочие дни     |
