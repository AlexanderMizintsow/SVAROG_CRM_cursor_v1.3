# Как проверить телефонию

Проверяйте под тремя людьми, иначе часть экранов будет пустой или закрытой.

- Менеджер компании: у него есть компании, где он региональный менеджер, МПП, МПР или замещающий, и рабочий добавочный в телефонах сотрудника.
- Руководитель отдела: должность «Руководитель отдела» или он указан руководителем отдела.
- Администратор без галочки статистики. У «Тест Тестов» нет своих компаний, поэтому список дел у него пустой. Это нормально.

Меню телефонии: слева **CRM → Телефония (asterisk)**.

Старые экраны **Пропущенные звонки**, **Обработанные звонки** и **Принятые звонки** должны открываться как раньше. Их не заменяли.

Кнопку **Позвонить** на этой машине лучше не нажимать на живой номер клиента: если АТС в этот момент примет команду, трубка менеджера реально зазвонит. На рабочей станции эту кнопку проверяют одним своим тестовым номером.

Команды ниже запускаются из папки `server/asterisk_server`. Они не звонят на АТС. Каждая в конце пишет одну строку и сама убирает пробные данные.

```
npm run replay-call
npm run replay-originate
npm run replay-window
npm run replay-followup
npm run replay-silence
npm run replay-hours
npm run replay-stats
npm run replay-recording
npm run replay-line
```

## 1. Повторный вход в АТС

Где смотреть: окно, где запущен `npm run dev`, строки сервиса АТС.

Как проверить: дождитесь строк `Connected to Asterisk AMI, login sent` и `AMI login accepted`. Если связь оборвалась, через несколько секунд снова должно быть `login sent`, а не молчаливое соединение без пароля.

Готово, если после обрыва вход повторяется сам и CRM при этом не падает.

## 2. Карточка звонка

Где смотреть: карточка компании, вкладка **История звонков**. Компании: **Дилеры**, или адрес `/add-dealers?company=5` для «Поволжснаб ООО», если эта компания есть.

Как проверить: у нового звонка видны направление (входящий или исходящий), дата, длительность разговора отдельно от ожидания, менеджер по добавочному. Один разговор — одна строка, а не пачка кусков. Номер с `+7`, `8` и `7` — это один и тот же телефон.

В базе у новой строки `calls` заполнены `direction`, `extension`, `uniqueid`, `talk_seconds`, `recording_path`. Старые строки могут быть пустыми в этих полях: у них длительность показана как «нет данных».

Команда: `npm run replay-call`.

## 3. История компании в обе стороны

Где смотреть: та же вкладка **История звонков**.

Как проверить: в списке есть и входящие, и исходящие. Звонок без комментария тоже виден. У исходящего менеджер стоит со стороны сотрудника, у входящего — со стороны компании. Внутренние разговоры сотрудников между собой в эту историю не попадают.

## 4. Дела на день

Где смотреть: **Телефония → Дела на день**, адрес `/notifications-asterisk-day`. Зайдите менеджером, у которого есть компании.

Как проверить: три группы.

- **Пропущенные без перезвона**
- **Перезвонить**
- **Пора позвонить**

У строки есть компания, телефон и кнопка **Позвонить**. Пропущенный не дублируется в «пора позвонить».

## 5. Звонок с карточки

Где смотреть кнопку **Позвонить**:

- строка в **Делах на день**;
- карточка компании, вкладка **Дилер**, у телефона компании;
- вкладка **Представители**, у телефона контакта.

Как проверить на рабочей станции, одним своим номером: после нажатия сначала звонит добавочный менеджера, и только потом набирается клиент. В консоли АТС строка вида `Набор отправлен: добавочный …`. Если АТС недоступна, появляется сообщение, что набор не отправлен, и станция при этом не ломается.

Добавочный берётся из телефона сотрудника с типом «рабочий» или «стационарный», длина 2–5 цифр. Стационарный важнее.

Команда без живого звонка: `npm run replay-originate`.

## 6. Окно в момент звонка

Где смотреть: всплывающее окно поверх CRM, когда идёт входящий или исходящий.

Как проверить на рабочей станции: в окне есть компания, контакт, последний комментарий, длительность после соединения. Можно открыть карточку компании. Если номера нет в базе, окно предлагает привязать его к дилеру. Окно не закрывается само, пока не сохранён итог.

Команда: `npm run replay-window`. Она проверяет состав окна и не рисует фальшивый звонок на экране.

## 7. Итог «перезвонить»

Где смотреть: окно звонка, итог **Перезвонить**, поле даты и времени. Потом **Дела на день**, группа **Перезвонить**.

Как проверить: без даты итог не сохраняется. После сохранения у этого менеджера и этой компании появляется напоминание «Перезвонить». Повторное сохранение того же звонка обновляет напоминание, а не создаёт второе. Если время вне рабочих часов, CRM сама переносит его на начало окна и пишет об этом.

Команда: `npm run replay-followup`.

## 8. Срок на пропущенный

Где смотреть: **Дела на день**. Форма **Срок на пропущенный, минут** видна руководителю, администратору и директору. Сейчас по умолчанию 15.

Как проверить: свежий пропущенный сразу есть у менеджера компании и нет у руководителя. Когда с момента пропуска прошло больше указанного срока, тот же пропущенный появляется и у руководителя отдела. Любой следующий разговор с этим номером убирает пропущенный из списка. Чужой отдел его не видит.

Команда: `npm run replay-followup`.

## 9. «Пора позвонить»

Где смотреть: **Дела на день**, группа **Пора позвонить**, и формы срока на этой же странице.

Как проверить:

- общий срок по умолчанию 14 дней, его меняет администратор или директор;
- срок отдела меняет руководитель этого отдела, пустое поле возвращает общий срок;
- свой срок менеджера важнее срока отдела;
- считаются и входящие, и исходящие;
- компания с открытым пропущенным остаётся в пропущенных, а не в этой группе;
- раз в день внутри рабочих часов таким компаниям создаётся напоминание «Пора позвонить».

Команда: `npm run replay-silence`.

## 10. Рабочие часы

Где смотреть: **Дела на день**. Строка «Напоминания о звонках: 09:00–18:00, общее окно». Форма **Общие рабочие часы** — у администратора и директора. Часы отдела — у руководителя отдела, сброс очищает оба поля.

Как проверить: напоминание о звонке, поставленное ночью, приходит утром в начале окна, а не среди ночи. Напоминания других типов от часов звонков не зависят. Окно отдела, если заданы оба края, заменяет общее.

Команда: `npm run replay-hours`. После проверки верните общее окно на 09:00–18:00, если меняли его на экране.

## 11. Статистика и галочка

Где смотреть:

- пункт **Статистика** внутри **Телефония**, адрес `/notifications-asterisk-stats`;
- галочка: **Телефония → Настройки**, блок **Кому видна статистика звонков**.

Как проверить:

- руководитель отдела видит пункт без галочки;
- администратор без галочки пункт не видит, по прямой ссылке экран пишет, что его открывают галочкой;
- руководитель, администратор или директор ставит галочку другому человеку и нажимает **Сохранить доступ**;
- после обновления страницы у этого человека появляется пункт **Статистика**;
- на экране есть период, число молчащих компаний, просроченные пропущенные, звонки за период, средний разговор, списки компаний и менеджеров;
- снимите галочку обратно и обновите страницу: пункт снова пропадает.

Команда: `npm run replay-stats`.

## 12. Прослушивание и отметка короткого или длинного

Где смотреть:

- **История звонков** компании: метки **Короткий** и **Длинный**, кнопка **Слушать**;
- порог: **Дела на день**, поля **Короткий разговор, до секунд** и **Длинный разговор, от секунд**. Сейчас 30 и 180. Меняет тот же человек, кто меняет срок пропущенного.

Как проверить:

- разговор короче порога помечен «Короткий», длиннее второго порога — «Длинный», средний без метки;
- кнопка **Слушать** есть только если сервер CRM видит файл. Папка АТС: `/var/spool/asterisk/monitor`. Пока папка серверу не видна, вместо кнопки остаётся надпись **Запись есть**;
- в плеере есть пауза и скорость 1×, 1.5×, 2×;
- свою запись слышит автор звонка, записи отдела — руководитель, остальным нужна та же галочка, что у статистики;
- администратор без галочки чужую запись не открывает.

Команда: `npm run replay-recording`.

## 13. Занятость линии

Где смотреть: цветная точка присутствия. Она есть в **Справочники → Иерархия сотрудников** и в чатах. Рядом с точкой появляется слово.

Как проверить на рабочей станции, когда АТС подключена: у сотрудника с рабочим добавочным во время гудков написано **звонит**, во время разговора **говорит**, после отбоя **свободен**. Это не то же самое, что точка «окно CRM открыто». Точка остаётся на месте, слово линии добавляется рядом.

Команда без живой станции: `npm run replay-line`.

## Что не входит в проверку

Автоперевод, живое прослушивание трубки, расшифровка в текст, обзвон списком, телефон в браузере, баллы качества, подсказка лучшего часа и второе закрепление дилера. Это отдельные решения, их в этой очереди нет.
