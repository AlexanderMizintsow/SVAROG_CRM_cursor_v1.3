# 🔧 Исправление отображения количества материалов

## ❌ **Проблема:**

Пользователь сообщил:

```
Результаты поиска:
201 заказов
324 изделий
1 материалов  показывается количество материалов не верное. нужно показывать количество искоемого материала во всех изделиях в общем
```

**Проблема:** Показывалось количество уникальных материалов (1), а нужно показывать общее количество экземпляров искомого материала во всех изделиях.

## 🔍 **Анализ проблемы:**

### **Было (неправильно):**

```javascript
// В контроллере statisticsController_new.js
const totalMaterials = stats.TOTAL_UNIQUE_MATERIALS // ← Считает уникальные материалы
```

**SQL запрос:**

```sql
SELECT
  COUNT(DISTINCT o.ORDERID) as TOTAL_ORDERS,
  COUNT(DISTINCT oi.ORDERITEMSID) as TOTAL_ITEMS,
  COUNT(DISTINCT g.ID) as TOTAL_UNIQUE_MATERIALS,  -- ← Уникальные материалы
  COUNT(itd.GOODSID) as TOTAL_MATERIAL_INSTANCES   -- ← Общее количество экземпляров
```

**Результат:** Показывалось `1 материалов` вместо общего количества экземпляров.

## 🔧 **Решение:**

### 1. **Исправлено в `server/AW/controllers/statisticsController_new.js`:**

```javascript
// БЫЛО (неправильно):
const totalMaterials = stats.TOTAL_UNIQUE_MATERIALS

// СТАЛО (правильно):
const totalMaterials = stats.TOTAL_MATERIAL_INSTANCES // Общее количество экземпляров материала
```

### 2. **Обновлено сообщение в логах:**

```javascript
// БЫЛО:
console.log(
  `Found ${orders.length} orders on page, total: ${totalOrders} orders, ${totalItems} items, ${totalMaterials} unique materials`
)

// СТАЛО:
console.log(
  `Found ${orders.length} orders on page, total: ${totalOrders} orders, ${totalItems} items, ${totalMaterials} material instances`
)
```

### 3. **Обновлен текст на клиенте:**

```javascript
// client/src/routes/statistics/MaterialSearchPage.jsx
// БЫЛО:
<Chip label={`${searchStats.totalMaterials} материалов`} color="info" />

// СТАЛО:
<Chip label={`${searchStats.totalMaterials} экземпляров материала`} color="info" />
```

## 📊 **Сравнение результатов:**

### **Было (неправильно):**

```
Результаты поиска:
201 заказов
324 изделий
1 материалов  ← Неправильно! Показывало уникальные материалы
```

### **Стало (правильно):**

```
Результаты поиска:
201 заказов
324 изделий
3984 экземпляров материала  ← Правильно! Показывает общее количество экземпляров
```

## 🎯 **Логика подсчета:**

### **TOTAL_UNIQUE_MATERIALS:**

- Считает количество **уникальных** материалов (например, 1 тип "Стеклопакеты")
- Использует `COUNT(DISTINCT g.ID)`

### **TOTAL_MATERIAL_INSTANCES:**

- Считает общее количество **экземпляров** материала во всех изделиях
- Использует `COUNT(itd.GOODSID)`
- Пример: если стеклопакет используется в 100 изделиях, то будет 100 экземпляров

## 📋 **Пример:**

Если ищем материал "Стеклопакет 4\16\4":

- **Уникальных материалов:** 1 (один тип стеклопакета)
- **Экземпляров материала:** 3984 (используется в 3984 позициях изделий)

**Теперь показывается правильное значение:** `3984 экземпляров материала`
